How the data works

Every five minutes

We poll selected stations using Iarnród Éireann's public realtime API every 5 minutes. All displayed times use Europe/Dublin, including daylight saving time.

The API gives local times without a clock-change marker. When clocks go back, a repeated time such as 01:30 is taken as the first one, before the change; if a train's expected time then reads earlier than its schedule, we note “clocks went back”. When clocks go forward, a skipped time such as 01:30 is read as 02:30.

What “late” means

The API's Late field reports delay in minutes. “On time” in the headline means early or no more than 1 minute late. Scheduled times are timetable times, using the arrival time for terminating trains.

A last reading, not a confirmed arrival

Each new poll replaces the stored reading for that train at that station on that date. The retained value is the last reading before a train leaves the board, not a confirmed arrival delay. A reading can change while the train remains on the board.

Current boards and network figures use only trains in each station’s latest successful poll; an empty board clears the station. Today’s performance keeps each train’s latest reading for the day, even after it leaves the board. Service details show the train code and earlier readings at other stations, not a live train location.

Coverage and gaps

A monitored station is reporting when its latest poll succeeded in the last {{ max_update_minutes() }} minutes, including a poll that returned no services. Limited coverage means fewer than all monitored stations are reporting. Stations with older data that we no longer poll are labelled “Not currently monitored”.

An empty board is a normal result, often overnight, and is shown as “No services returned”. After a failed update, or once a station’s latest successful poll is {{ max_update_minutes() }} minutes old, its last board stays visible on its station page and the map, marked as not current, and is left out of current network figures. The Data status page shows each station’s latest poll: trains returned, no services returned, or a failed update. A network figure describes tracked trains, not the whole railway.

Starts, calls and terminations

“Terminates here” means the destination matches the station name; “Starts here” means the origin matches. Otherwise we show “Calling service”. These labels are name-based inferences, so differences in names can affect them.

Independent project

Dublin Rail Tracker is built and maintained by Daniel English. It is an independent project, not affiliated with Iarnród Éireann, using their public realtime API.
